# Java

This repository documents my progress learning Java through
programming exercises and practical projects.

My goal is to develop a strong understanding of programming
fundamentals and apply them to solve problems independently.

## Approach

My aim is to move from understanding examples to designing solutions
of my own. As the collection grows, I will document how I approach
problems, test my assumptions, and improve my code.

## Topics

- Variables, data types, and operators
- User input and output
- Conditionals and loops
- Methods and problem decomposition
- Arrays and strings
- Classes and object-oriented programming
- File handling and exceptions

## Reading the Work

Exercises will be organized by topic. Larger projects will include
a description of the problem, the approach taken, and instructions
for running the program. Selected notes will explain challenges
encountered and what changed between attempts.
