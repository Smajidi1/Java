# Java Programming Fundamentals

## Overview

This repository documents my progress learning Java through
programming exercises and practical projects following the book
"Introduction to Java Programming and Data Structures, Comprehensive
Version, 11th edition".

My goal is to develop a strong understanding of programming fundamentals
and apply that knowledge to solve problems independently. I am building
this foundation through chapter exercises, annotated code, and an
electronic lab notebook where I record concepts, explanations, useful
shortcuts, and key observations as I work through the book.


## Learning Approach

My current focus is Chapters 1–8, which the textbook identifies as the
fundamentals of programming. I work through the exercises, run my code,
and check the results against what each problem asks for. My notebook
includes notes on how I approached the problems and the concepts I
needed to review.

## Topics Covered in Chapters 1–8

- Java program structure, compilation, and execution
- Variables, constants, primitive data types, and type conversion
- Arithmetic, comparison, and logical operators
- Console input and formatted output
- Conditional statements: if, else, and switch
- Mathematical functions, characters, and strings
- Loops: while, do-while, for, and nested loops
- Methods, parameters, return values, and method overloading
- Problem decomposition and method reuse
- Single-dimensional arrays and array processing
- Basic searching and sorting with arrays
- Multidimensional arrays and matrix processing
- Identifying syntax, runtime, and logic errors
